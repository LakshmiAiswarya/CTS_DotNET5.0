# Student Course Portal - Angular 20

## Project Overview
Student Course Portal is an Angular 20 application developed as part of Digital Nurture 5.0 Hands-on Exercises.

The project was built step-by-step by implementing Angular concepts from basic components to advanced topics like NgRx and testing.

---
## Tools Used

- Angular 20
- Angular CLI
- Node.js
- npm
- TypeScript
- HTML
- CSS
- VS Code
- Angular Language Service
- Chrome Angular DevTools
- JSON Server
- NgRx
- Jasmine
- Karma


## Hands-On Implementation

### Hands-On 1: Environment Setup, Project Structure & First Component
- Created Angular project using Angular CLI.
- Explored Angular project structure and configuration files.
- Created initial components:
  - Header
  - Home
  - Course List
  - Student Profile
- Added basic header navigation and home dashboard content.

### Hands-On 2: Components, Data Binding & Lifecycle Hooks
- Implemented Angular components.
- Used property binding and interpolation.
- Applied component lifecycle hooks for handling component events.

### Hands-On 3: Directives & Pipes
- Implemented Angular structural directives:
  - *ngFor
  - *ngIf
- Created and used pipes for data transformation.
- Added attribute directive functionality.

### Hands-On 4: Template Driven Forms
- Created enrollment form using template-driven forms.
- Added form controls and validations.
- Handled user input.

### Hands-On 5: Reactive Forms & Validation
- Implemented reactive forms using FormGroup and FormControl.
- Added validation and error handling.

### Hands-On 6: Services & Dependency Injection
- Created Angular services.
- Used dependency injection for sharing application data.

### Hands-On 7: Routing & Route Guards
- Implemented Angular routing.
- Added navigation between pages.
- Implemented route guards for protected routes.

### Hands-On 8: HTTP Client Integration
- Integrated REST API using HttpClient.
- Connected application with JSON Server.
- Implemented HTTP error handling and interceptors.

### Hands-On 9: State Management using NgRx
- Implemented NgRx store.
- Created:
  - Actions
  - Reducers
  - Effects
  - Selectors
- Managed application state.

### Hands-On 10: Unit Testing
- Implemented testing using Jasmine and Karma.
- Added component and service test cases.
