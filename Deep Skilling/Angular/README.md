# Student Course Portal - Angular]

## Project Overview
Student Course Portal is a standalone Angular application developed as part of Cognizant Digital Nurture Deep Skilling Program.
The application demonstrates Angular concepts including components, data binding, directives, forms, services, routing, HTTP communication, NgRx state management and unit testing.

## Technologies Used
- Angular 21
- TypeScript
- HTML5
- CSS3
- RxJS
- Angular Router
- Angular Forms
- Angular HttpClient
- NgRx Store
- Vitest Testing
